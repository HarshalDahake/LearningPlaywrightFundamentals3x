Playwright Architecture In Depth

Playwright is Microsoft's modern browser automation framework. Unlike Selenium, Playwright communicates with browser engines using browser-specific protocols and manages multiple isolated Browser Contexts within a single browser process.

Execution Flow

  1. Test script triggers Playwright API.
  2. Playwright sends commands to browser protocol.
  3. Browser creates isolated Browser Context.
  4. Pages are opened inside the context.
  5. Actions, assertions, screenshots and traces are executed.

Browser Context Internals

Browser
 |
 +-- Context 1 (User A)
 |      +-- Page 1
 |      +-- Page 2
 |
 +-- Context 2 (User B)
 |      +-- Page 1
 |
 +-- Context 3 (User C)
        +-- Page 1

Each context has its own cookies, storage, permissions and authentication state. This makes parallel execution highly efficient.

Why Playwright is Fast

  • Auto waiting for stable elements.
  • Browser contexts instead of multiple browser instances.
  • Direct communication with browser engines.
  • Parallel execution support.
  • Built-in tracing and debugging.

Interview Questions & Answers

1. Explain Playwright Architecture.

Playwright uses client APIs which communicate with browser engines through browser protocols. Browser Contexts provide lightweight isolated sessions for parallel execution.

2. What is Browser Context?

An isolated browser session having separate cookies, storage and permissions while sharing the same browser process.

3. Why is Playwright faster than Selenium?

Due to direct browser communication, efficient waiting mechanisms and lightweight Browser Contexts.

4. Difference between Locator and ElementHandle?

Locators are recommended because they automatically re-query elements and support auto-waiting.

5. What is Auto-Waiting?

Playwright automatically waits until an element becomes actionable before performing operations.

6. How does Playwright support parallel execution?

Using workers and Browser Context isolation.

7. What is Trace Viewer?

A debugging tool that captures screenshots, DOM snapshots, console logs and network calls.

8. Difference Between Selenium and Playwright?

Selenium depends on WebDriver; Playwright uses browser protocols and includes modern testing capabilities out of the box.

9. What are Playwright Locators?

getByRole(), getByLabel(), getByText(), getByPlaceholder(), getByTestId().

10. What are the advantages of Playwright?

  • Cross-browser support
  • Auto waits
  • Trace viewer
  • API testing
  • Parallel execution
  • Network interception
